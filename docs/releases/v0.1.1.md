## The shared client id

A security read asked whether the client id, shared by every request of one `Client`, is a risk. It is not, on its own. A party that has seen it can name the client's reply namespace and link the client's requests ([ADR-0005](../decisions/0005-a-reply-route-token-carries-at-least-128-bits.md) records that). It cannot answer one of them: a NATS publish reaches only an exact subject, so it would have to name a 130-bit route token it has not seen, and the mux drops and counts a reply whose token matches no route. It cannot read the replies either, unless NATS grants it a subscription on that namespace.

