# Code of Conduct

This project follows the [CNCF Code of Conduct](https://github.com/cncf/foundation/blob/main/code-of-conduct.md).

By taking part, you agree to uphold it. To report unacceptable behaviour, follow the reporting
instructions in the CNCF Code of Conduct, or contact the maintainers privately through a
[GitHub security advisory](SECURITY.md) on this repository if the matter cannot go elsewhere.
